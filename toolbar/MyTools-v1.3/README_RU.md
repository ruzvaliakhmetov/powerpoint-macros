# My Tools v1.3 — PowerPoint for Mac

Вкладка **My Tools** с пятью кнопками и исходными иконками с прозрачным фоном:

- **Copy Radius / Paste Radius** — перенос абсолютного радиуса скругления.
- **Build Links** — создание ссылок галереи; спрашивает **First slide** и **Last slide**.
- **Copy Geometry / Paste Geometry** — перенос положения, размера и поворота видео.

**Без кнопки Test VBA.** Подтверждения успешного копирования и вставки убраны. Предупреждения о неверном выделении/отсутствии скопированных параметров сохраняются. Для Build Links итоговое сообщение остаётся.

## Обновление с v1.1 или v1.2, если исходный `.pptm` сохранился

1. В PowerPoint открой исходный `.pptm` (не текущую рабочую презентацию).
2. Открой **Tools → Macro → Visual Basic Editor**.
3. Найди модуль со старыми макросами, выдели **весь его код**, замени содержимым файла `MyTools_Paste_Into_Module.txt` из этого комплекта. Это заменяет все шесть старых процедур и callbacks разом — без ручного поиска строк. **Не создавай второй модуль с теми же процедурами.**
4. Сохрани `.pptm`, через **File → Export** получи **PowerPoint Add-in (`.ppam`)**. Если можно, используй новое имя `MyTools-v1.3.ppam`.
5. Полностью выйди из PowerPoint (`Cmd + Q`).
6. Запусти команду в Terminal: введи `bash ` (с пробелом), перетащи `Install_MyTools_Ribbon.command` в окно и нажми Return. Выбери только что экспортированный `.ppam`.
7. Запусти PowerPoint, в **Tools → PowerPoint Add-ins** удали из списка прежний аддин и подключи полученный `MyTools-v1.3-Ribbon.ppam`.

## Если исходного `.pptm` нет

1. Создай новую презентацию, открой Visual Basic Editor → **Insert → Module**.
2. Вставь **весь** `MyTools_Paste_Into_Module.txt` в пустой модуль. Альтернатива: импортируй `MyTools.bas` и убедись, что он появился в Project Explorer.
3. Для проверки запусти `CopyCornerRadius` с выделенным скруглённым прямоугольником: он должен завершиться **без сообщения**. При отсутствии выделения он покажет предупреждение.
4. Сохрани как `.pptm`, экспортируй в `.ppam` и выполни шаги 5–7 предыдущего раздела.

## Что внутри

- `MyTools_Paste_Into_Module.txt` — готовый VBA для вставки.
- `MyTools.bas` — тот же код для импорта в VBA.
- `customUI14.xml` и `customUI14.xml.rels` — разметка вкладки.
- `icons/` — пять PNG-иконок с прозрачностью.
- `Install_MyTools_Ribbon.command` — внедрение Ribbon XML и PNG в экспортированный `.ppam`.

**Важно:** результат сборки — новый `.ppam`; исходный файл не перезаписывается. Просто удалить Test VBA из уже установленного `.ppam` обновлением XML можно, но это не устранит прежние подтверждения, поскольку они находятся внутри VBA. Для изменения VBA необходим новый экспорт.
